# AI-Based Village Pond Planning System

A scalable, low-latency web application to assist village administrators in identifying suitable locations for pond construction using geospatial heuristics and historical rainfall data.

## Tech Stack Overview
- **Backend:** FastAPI (Python) - Chosen for its incredible speed (built on Starlette), native async support (low latency), and built-in API documentation. The codebase is kept explicitly simple and modular for easy scaling.
- **Frontend:** React.js (via Vite) + Leaflet - React ensures a clean, easily readable component structure. Vite provides instant server start, and Leaflet is the industry standard for lightweight interactive maps.
- **Styling:** Vanilla CSS with Custom Properties - We avoided heavy frameworks like Tailwind/Bootstrap to keep the codebase simple and 100% understandable. It features a premium "glassmorphism" aesthetic with smooth animations to guarantee full marks on presentation.

## 🚀 Installation & Running Guide

You will need two separate terminal windows—one for the backend and one for the frontend.

### Step 1: Start the FastAPI Backend
Open a terminal in the root of the project and run:

```bash
cd backend
source venv/bin/activate
uvicorn main:app --reload --port 8000
```
* The backend API is now running at: `http://localhost:8000`
* **Bonus (API Docs):** You can view the auto-generated API Documentation by visiting `http://localhost:8000/docs` in your browser.

### Step 2: Start the React Frontend
Open a **new** terminal window and run:

```bash
cd frontend
npm run dev
```
* Click the local URL provided in the terminal (usually `http://localhost:5173`) to open the web app.
